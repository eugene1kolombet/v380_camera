# V380 — клиент камеры на C++ (Windows/MSVC)

Нативная программа для камеры V380 Pro: вход, привязка к Wi-Fi, список записей
и скачивание видео (с SD-карты) в mp4 со звуком.

Зависимости — только Windows: **Winsock2** (сеть) и **BCrypt** (AES-128, SHA-256).
X25519 встроен в исходник (TweetNaCl). Для сборки mp4 вызывается **ffmpeg** (если он
в PATH); иначе сохраняются сырые потоки `.h264` и `.alaw`.

## Сборка

Двойным кликом/из cmd:

```bat
build.bat
```

(скрипт подхватывает окружение Visual Studio 2022 и запускает `cl`). Или вручную из
«x64 Native Tools Command Prompt for VS 2022»:

```bat
cl /EHsc /O2 v380.cpp
```

Получится `v380.exe`. Проверено на MSVC 14.39 (Visual Studio 2022 Community).

## Использование

```bat
rem список записей на SD-карте
v380.exe --ip 192.168.10.5 --password <пароль_камеры> list

rem скачать запись №0 в mp4 (видео H.264 1280x720 + аудио)
v380.exe --ip 192.168.10.5 --password <пароль_камеры> download --seg 0 --out rec.mp4

rem привязать камеру к Wi-Fi (камера в режиме AP, ПК подключён к её Wi-Fi)
v380.exe --password <пароль_камеры> provision --ssid <сеть> --wifi-password <пароль_wifi>
```

- `--password` — пароль камеры с наклейки (поле **Password**).
- IP камеры в своей сети смотрите в роутере; в режиме точки доступа (AP) камера по
  адресу `192.168.1.1` — его для `provision` указывать не нужно.

## Как это работает (кратко)

- TCP на порт **8089**; вход — обмен ключами **X25519** + проверка пароля
  (`sha256(pub‖пароль)`), даёт сессионный ключ.
- Все пакеты: 16-байтный заголовок + JSON, шифрованный **AES-128-CBC** (ключ из сессии).
- Список записей — метод `REC_FILE_LIST`; воспроизведение — `REPLAY_CTRL` с
  `video:1,audio:1` и пополнением кредита кадров.
- Кадр: 32-байтный заголовок (CBC) с длинами открытой/шифрованной частей, тело —
  выборочно AES-CBC. Видео — H.264, аудио — **G.711 A-law** (16 кГц моно).

Полный разбор протокола — в `..\client\PROTOCOL_NOTES.md`.
